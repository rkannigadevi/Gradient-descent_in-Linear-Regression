Understanding Gradient Descent

Linear Regression Visual Lab: Watch how error reduces mathematically step-by-step

Training Dataset

Our goal is to find the best-fit line for this data:

Hours (x) Marks (y)
1 2
2 4
3 6

Model Equation: ŷ = mx + c

Where \( m \) is slope and \( c \) is intercept.

Cost Function (MSE): \[ J = \frac{1}{n} \sum (y - \hat{y})^2 \]

Algorithm Process

From the sample dataset, it is clearly known that the relation is roughly:

\( y = 2x \)

But assume the machine does NOT know this.

Step 0: Initialize Values (Blind Guess)

Let’s start with wrong values:

\( m = 0, \quad c = 0 \)

So the initial model is: \(\hat{y} = 0\)

Gradient Descent keeps repeating:

  • 1 Compute predictions
  • 2 Compute error
  • 3 Compute gradients
  • 4 Update parameters

Eventually:

\( m \approx 2, \quad c \approx 0 \)
\( J(m,c) \approx 0 \)
